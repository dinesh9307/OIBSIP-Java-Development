# Online Reservation System - Core Java

## OIBSIP Java Development Internship 

A console-based Online Reservation System developed using Core Java.

## Features

- User registration
- User login/authentication
- Train search
- Train availability
- Ticket booking
- Passenger details
- PNR generation
- Ticket display
- Ticket cancellation
- Booking history
- Input validation
- Exception handling
- Java Collections
- Date and time

## Technologies

- Java
- Core Java
- OOP
- ArrayList
- HashMap / LinkedHashMap
- Scanner
- LocalDateTime

## How to Run

### Using terminal

Open the `src` folder and run:

```bash
javac *.java
java Main
```

### Demo login

Username: `admin`

Password: `admin123`

You can also register a new user from the application.
